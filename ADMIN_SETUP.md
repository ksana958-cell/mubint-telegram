# Админ-панель Кампуса

1. Узнайте **числовой Telegram user ID** аккаунта @bot_shen (например, через проверенного бота для определения ID).
2. В переменных окружения BotHost установите `ADMIN_TELEGRAM_ID` равным этому числу. Не вписывайте username.
3. Перезапустите приложение и откройте Mini App через Telegram. В «Ещё» → «Настройки» появится «Админ-панель».
4. Только Telegram initData, проверенный сервером по подписи BOT_TOKEN, и точное совпадение user ID дают доступ к `/api/admin/*`. При отсутствии ID панель закрыта для всех.

В панели: число пользователей, групп, домашних заданий, очередь уведомлений, состояние последней проверки и ручной запуск проверки расписания. Отправка массовых сообщений намеренно не добавлена без отдельного согласования.

Кнопка «Просмотрено» для изменений сохранена из предыдущей версии; статус хранится локально для данного устройства.
