# Кампус: исправление кнопки «Просмотрено» и админ-панели

## Почему функций не видно
В полученном архиве `app/campus-app.tsx` уже содержит оба компонента, а `server/http.mjs` — защищённые admin API. Но `web/index.html` подключал старый `/assets/index-Qbb_U3Q-.js`, который не содержит ни одной из этих функций. Без новой сборки JS Telegram показывает старый интерфейс независимо от `ADMIN_TELEGRAM_ID`.

## Способ А: автоматически через GitHub Actions (рекомендуется)
1. **Сделайте резервную копию данных BotHost** (`/app/data`, включая SQLite). Не загружайте папку data в GitHub.
2. **Скопируйте содержимое этого архива в корень репозитория** (не дополнительной вложенной папкой) и сделайте Commit to main → Push origin через GitHub Desktop. Папки `app`, `web`, `server`, `.github` должны лежать на одном уровне с `Dockerfile` и `app.js`.
3. На github.com откройте репозиторий → **Actions** → **Build Campus frontend (web)**. Подождите зелёного статуса. Workflow автоматически выполнит `npm ci`, `npm run check`, тесты и `npm run build`, затем добавит на GitHub отдельный коммит с новыми файлами `web`.
4. Если workflow пишет `Permission denied to github-actions[bot]`, включите **Settings → Actions → General → Workflow permissions → Read and write permissions**; запустите Workflow снова через Run workflow. Если действия отключены — включите Actions.
5. Дождитесь нового коммита **Build Campus UI: reviewed changes and admin** в истории, только после этого выполните **обновление из GitHub и полное развёртывание** на BotHost. Простого перезапуска может быть недостаточно.
6. Откройте Mini App заново через кнопку Telegram-бота. Изменения отображаются на главной при наличии непросмотренных событий, кнопка «Просмотрено» появляется под блоком. Админ-панель — Ещё → Настройки → Админ-панель (внизу).

## Способ Б: локальная сборка на Windows
1. Установите Node.js 24 и запустите в распакованной папке `СОБРАТЬ_ИНТЕРФЕЙС.cmd`.
2. Убедитесь в сообщении `OK: актуальный интерфейс`.
3. В GitHub Desktop отправьте изменённые файлы (особенно папку `web/`) через Commit → Push origin.
4. Обновите на BotHost, закройте и откройте Mini App.

## Проверка администратора
- В BotHost `ADMIN_TELEGRAM_ID` должен быть **числовым Telegram user ID** именно твоего аккаунта, а не `@bot_shen`, ссылкой или ID бота. Пробелы по краям автоматически удаляются.
- После рестарта в логах будет `Кампус: админ-панель настроена по Telegram ID.` Если лог сообщает, что она выключена, BotHost не передаёт переменную корректно.
- Открывать Mini App нужно **из Telegram**. Сервер проверяет подпись `initData` через `BOT_TOKEN`, и без неё админ-раздел не откроется.
- При несовпадении числового ID панель скрыта и API отвечает 403 — это нормальная защита.
- В браузере откройте `https://АДРЕС_МИНИ-ПРИЛОЖЕНИЯ/health`: после обновления сервер должен вернуть `"adminConfigured":true` и `"frontendFeatures":"ready"`. Если `old_build` — по-прежнему старая сборка. Если этих ключей вообще нет — сервер BotHost тоже не обновился. Переменная должна быть числовым ID владельца. Также можно запустить `npm run verify:build`.

**Безопасность:** не публикуйте в GitHub `BOT_TOKEN`, `.env`, `data/`, базу SQLite или приватные домашние задания.
