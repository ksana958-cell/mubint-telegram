# Обновление «Кампуса» до 2.0

1. Останови бота и сохрани резервную копию `/app/data`.
2. Распакуй архив и обнови все файлы внутри папки `mubint-telegram` в существующем репозитории. Не загружай ZIP одним файлом; `app.js` и `Dockerfile` остаются в корне.
3. Сохрани на хостинге базу `/app/data`, токен, `APP_URL` и прежние переменные. В архиве нет рабочей базы или секретов.
4. Выполни повторное развёртывание в BotHost с собственным `Dockerfile` из архива: он использует Node.js 24.
5. Полностью закрой и заново открой приложение в Telegram.

Проверка расписания: **каждый день в 20:00 по Москве**. В разделе «Изменения» это видно сразу. Утренняя сводка включается отдельно: «Ещё» → «Настройки» → выбери время → «Сохранить настройки».

ДЗ с фото: нажми на пару → «Снять фото» или «Из галереи» → при желании добавь пункты → «Сохранить задание». Текст необязателен. ДЗ привяжется к следующей опубликованной дате этого предмета. Фото доступны только тебе.

В «Ещё» доступны предметы, настройки и ярлык. Кнопка «Поделиться расписанием» находится над карточкой дня. Подробности и ограничения платформы — в README.md.

База обновляется без удаления старых ДЗ. Если нужно вернуться к прошлой версии, восстанови предыдущие файлы приложения; базу не очищай. Сначала используй резервную копию только на отдельной проверочной установке, чтобы не потерять новые задания.
